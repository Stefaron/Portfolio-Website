# Project notes

Multipage Astro portfolio. The design reference is the pen.dev export at
`../design/portfolio-export.html` (outside this project); treat it as read-only.

## Commands

- `npm run dev` — dev server
- `npm run check` — Astro type/content check
- `npm run build` — static build to `dist/`
- `npm run preview` — serve the production build
- `npm run smoke -- http://localhost:4322` — headless Chrome smoke test
- `npm run format` — Prettier + `prettier-plugin-astro`

Use background mode for the dev server per the instructions below.

## Architecture

- `src/pages/*` is the composition root. Pages fetch data from `src/lib/content.ts`
  and pass it down as props.
- `src/components/sections/*` are presentational and must not import `astro:content`.
- `src/components/ui/*` are primitives and must not import content or config.
- `src/content/*` is the editable content database; schemas live in
  `src/content.config.ts`.
- Site identity, contact details, nav, and hero copy live in `src/config/site.ts`.
- Design tokens live in the `@theme` block of `src/styles/global.css`. Use semantic
  utilities (`bg-canvas`, `text-ink`, `bg-paper`, etc.), not raw hex values.

## Generated files

- `public/cv/stefaron-cv.pdf` is generated by `npm run cv`.
- `public/og-image.png`, `public/apple-touch-icon.png` are generated by
  `npm run assets:brand`.
- Do not edit `dist/`, `.astro/`, or `src/assets/images/` by hand unless replacing
  the source asset intentionally.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
